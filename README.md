# مهوا — دستیار هوشمند

مهوا یک رابط گفت‌وگوی فارسی و راست‌چین است که به شکل **PWA قابل نصب روی اندروید** و یک **پوستهٔ بومی Android با Capacitor** آماده شده است.

> مهوا خودش مدل زبانی یا سرویس ابری همراه ندارد. برای تولید پاسخ هوشمند، نشانی یک API سازگار با قالب OpenAI Chat Completions، نام مدل و در صورت نیاز کلید API را در «تنظیمات اتصال» وارد کنید. بدون اتصال، برنامه آفلاین و صریحاً در حالت نمایشی است و پاسخ واقعی را جعل نمی‌کند.

## قابلیت‌ها

- رابط فارسی و راست‌چین، سازگار با موبایل و دسکتاپ
- نصب به‌صورت PWA و نگهداری پوسته برای استفادهٔ آفلاین
- نسخهٔ بومی اندروید با نام و آیکن مهوا
- تاریخچهٔ گفت‌وگوها، پوستهٔ روشن/تیره، کپی پاسخ و شروع گفت‌وگوی تازه
- دکمهٔ «ChatGPT رسمی» که اپ ChatGPT اندروید (اگر نصب باشد) یا وب‌سایت رسمی را باز می‌کند؛ گفتگو در خود ChatGPT ادامه می‌یابد و نیازی به API ندارد
- اتصال اختیاری به APIهای سازگار با `POST /v1/chat/completions`
- پاک‌کردن گفت‌وگوها و تنظیمات ذخیره‌شده از داخل برنامه

## نصب روی اندروید از مرورگر

1. برنامه را روی یک میزبان HTTPS منتشر کنید (یا در محیط توسعه با `localhost` باز کنید).
2. نشانی آن را با Chrome در گوشی اندرویدی باز کنید.
3. از اعلان نصب برنامه یا منوی Chrome، **Install app / افزودن به صفحهٔ اصلی** را انتخاب کنید.

برای پیش‌نمایش توسعه:

```bash
npm run serve
```

سرویس روی پورت `4173` اجرا می‌شود. برای نصب روی گوشی، آن را از طریق نشانی HTTPS قابل دسترس کنید؛ نشانی `localhost` رایانه روی خود گوشی در دسترس نیست.

## ساخت APK اندروید

پیش‌نیازها: Node.js 20 یا جدیدتر، JDK 21، Android SDK و Android platform/build-tools نسخهٔ 35.

```bash
npm ci
npx cap sync android
cd android
./gradlew assembleDebug
```

فایل نصب‌شدنی در این مسیر ساخته می‌شود:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

در ویندوز از `gradlew.bat assembleDebug` استفاده کنید. همچنین GitHub Actions با اجرای دستی یا هر push روی `main` و شاخه‌های `arena/**`، APK آزمایشی را به‌عنوان artifact با نام `mahva-android-debug-apk` منتشر می‌کند. این APK با کلید debug امضا می‌شود و برای نصب مستقیم/آزمایش است، نه انتشار نهایی در فروشگاه.

## اتصال مدل

در برنامه **تنظیمات اتصال** را باز و این موارد را وارد کنید:

- **نشانی کامل Chat Completions**؛ برای نمونه `https://api.openai.com/v1/chat/completions` (نشانی دقیق به ارائه‌دهنده بستگی دارد)
- **نام مدل** مورد پشتیبانی ارائه‌دهنده
- **کلید API** در صورت نیاز سرویس

API باید درخواست‌های مرورگر را از طریق CORS بپذیرد. مهوا درخواست را مستقیماً از دستگاه شما به نشانی واردشده می‌فرستد و سرور واسطی ندارد.

## نکتهٔ امنیت و حریم خصوصی

گفت‌وگوها، تنظیمات و کلید API در `localStorage` همان مرورگر/دستگاه ذخیره می‌شوند؛ این داده‌ها **به‌صورت جداگانه رمزگذاری نمی‌شوند**. هر کسی که به داده‌های مرورگر دستگاه دسترسی داشته باشد ممکن است آن‌ها را ببیند. برای همین از کلید مشترک یا کلیدی که دسترسی گسترده دارد استفاده نکنید و پس از استفادهٔ دستگاه مشترک، از دکمهٔ پاک‌کردن داده‌ها استفاده کنید. با اتصال مدل آنلاین، متن گفت‌وگو برای دریافت پاسخ به ارائه‌دهندهٔ API انتخابی ارسال می‌شود و ممکن است مشمول هزینه و سیاست نگهداری دادهٔ همان ارائه‌دهنده باشد.
