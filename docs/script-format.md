# قالب متن سِناوریو در مهوا

هر فایل متنی ساده (Markdown) می‌تواند سِناوریوی ویدیو باشد. دو مفهوم اصلی داریم:

- **دستور** (`@key value`): تنظیمات پروژه یا صحنه.
- **متن آزاد**: آنچه روی کارت نوشته و خوانده می‌شود.

```
# عنوان کل ویدیو
@theme midnight
@resolution landscape

متن مقدمه…

## عنوان صحنه
@image photos/one.jpg
متن صحنه…
```

---

## ۱. دستورهای سطح پروژه

این دستورها هر جایی از فایل بیایند روی کل ویدیو اثر دارند (اگر پیش از نخستین
`##` بنویسید، خواناتر است).

| دستور | مقادیر | پیش‌فرض | توضیح |
|---|---|---|---|
| `@theme` | `midnight` `sunset` `forest` `amber` `paper` `ink` | `midnight` | تم رنگی |
| `@resolution` / `@size` | `landscape` `portrait` `square` `portrait-4-5` `hd` `uhd` یا `1920x1080` | `landscape` | ابعاد قاب |
| `@fps` | عدد | `30` | فریم بر ثانیه |
| `@font` | نام خانوادهٔ فونت | `Vazirmatn` | فونت متن (وزیرمتن همراه پروژه است) |
| `@rtl` / `@ltr` | پرچم | `rtl` | جهت متن |
| `@language` | `fa` `en` `ar` … | `fa` | زبان متن و انتخاب صدا |
| `@transition` | `fade` `circleopen` `slideleft` `dissolve` `hblur` … | `fade` | نوع کراس‌فید |
| `@transition_duration` | ثانیه | `0.6` | مدت کراس‌فید |
| `@kenburns` | `auto` `in` `out` `pan-right` `pan-left` `none` | `auto` | حرکت دوربین |
| `@voice` | نام صدا (مثل `fa-IR-DilaraNeural`) | خودکار | صدای گوینده |
| `@voice_engine` | `auto` `edge` `sapi` `say` `espeak` `pico` `piper` `silent` | `auto` | موتور صدا |
| `@rate` | `+10%` `-15%` | `+0%` | سرعت گفتار |
| `@pitch` | `+5Hz` | `+0Hz` | زیر و بمی صدا (edge) |
| `@voice_volume` | ۰ تا ۲ | `1` | بلندی نریشن |
| `@music` | مسیر فایل | — | موسیقی پس‌زمینه (لوپ می‌شود) |
| `@music_volume` | ۰ تا ۱ | `0.07` | بلندی موسیقی |
| `@pad` | ثانیه | `0.65` | سکوت ابتدا و انتهای هر صحنه |
| `@min_scene` / `@max_scene` | ثانیه | `3` / `120` | کف و سقف مدت صحنه |
| `@chunk` | تعداد کاراکتر | `420` | صحنه‌های بلندتر خودکار به چند صحنه شکسته می‌شوند |
| `@words_per_second` | عدد | `2.45` | سرعت تخمینی خواندن (وقتی صدایی وجود ندارد) |
| `@quality` | `fast` `balanced` `high` | `balanced` | کیفیت خروجی |
| `@out` | نام فایل | `video.mp4` | نام فایل خروجی |
| `@subtitle_band` | پرچم | `false` | نوار تیرهٔ زیرنویس |

> یک تم روشن (`paper` / `ink`) به‌معنای متن تیره است؛ مهوا پوشش روی تصویر را
> خودکار روشن می‌کند تا متن خوانا بماند.

---

## ۲. دستورهای سطح صحنه

هر `##` یک صحنهٔ جدید می‌سازد. این دستورها فقط روی همان صحنه اثر دارند و باید
پس از `##` نوشته شوند.

| دستور | مقادیر | توضیح |
|---|---|---|
| `@image` | مسیر فایل یا نام فایل | تصویر صحنه (در رابط وب، نام فایل آپلودشده کافی است) |
| `@duration` | ثانیه (`12`، `12s`، `1:30`) | مدت دلخواه؛ اگر صدا بلندتر باشد، مدت افزایش می‌یابد |
| `@layout` | `auto` `title` `overlay` `split` `plain` | چیدمان کارت |
| `@title` `@subtitle` `@body` | متن | جایگزین/تکمیل متن خودکار |
| `@narration` | متن | متنی که «خوانده» شود، متفاوت از متن نمایشی |
| `@voice_file` | مسیر فایل صوتی | صدای آمادهٔ این صحنه (نریشن دستی) |
| `@accent` | رنگ hex مثل `#ff8800` | رنگ تأکیدی این صحنه |
| `@theme` | نام تم | تم متفاوت برای همین صحنه |
| `@transition` | نوع کراس‌فید | ترنزیشن ورود به صحنهٔ بعد |
| `@kenburns` | حالت حرکت | `in` `out` `pan-right` `pan-left` `none` |
| `@layout` | — | `plain` (فقط متن)، `overlay` (متن روی عکس)، `split` (عکس بالا، متن پایین)، `title` (کارت عنوان بزرگ) |

### قاعدهٔ خودکار متن

- نخستین پاراگراف آزاد هر صحنه → **سرنویس (subtitle)**.
- پاراگراف‌های بعدی → **متن بدنه (body)**.
- خطوطی که با `-`، `*` یا `1.` شروع شوند → **فهرست نقطه‌ای**.
- صحنه‌های طولانی‌تر از `@chunk` کاراکتر، خودکار به چند صحنهٔ خوانا شکسته می‌شوند.

---

## ۳. چیدمان کارت‌ها (`@layout`)

| مقدار | نتیجه |
|---|---|
| `auto` | اگر تصویر بدهید `overlay`، وگرنه `plain` (صحنهٔ اول در حالت‌های خاص `title`) |
| `title` | کارت عنوان: تایپوگرافی درشت و وسط قاب، بدون بدنه |
| `overlay` | تصویر تمام‌قاب + پردهٔ تطبیقی + متن پایین |
| `split` | تصویر در بالا، متن روی پس‌زمینهٔ گرادیانی در پایین |
| `plain` | فقط پس‌زمینهٔ گرادیانی تم + متن (سریع‌ترین حالت) |

## ۵. نکته‌های کار با پروژه‌های طولانی

- **زمان‌بندی:** `python -m mahva plan story.md` پیش از رندر، مدت و تعداد صحنه‌ها
  را نشان می‌دهد.
- **دستهٔ کراس‌فید:** اگر تعداد صحنه‌ها زیاد است (بیش از ۱۰)، مهوا خودکار کلیپ‌ها
  را در دسته‌های کوچک ترکیب و بعد دسته‌ها را ادغام می‌کند. با
  `--group 5` می‌توانید اندازهٔ دسته را دستی تعیین کنید.
- **ادامهٔ رندر:** اگر رندر نیمه‌کاره بماند، اجرای دوباره فقط صحنه‌های ناتمام را
  می‌سازد (حافظهٔ موقت در `out/work/manifest.json`). با `--force` از صفر شروع کنید.
- **پیش‌نمایش سریع:** با `--preview` یک نسخهٔ کوچک و سریع بسازید تا زمان‌بندی و
  متن‌ها را بررسی کنید.
